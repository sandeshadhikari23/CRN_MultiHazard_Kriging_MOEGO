# 02 — High-Fidelity Simulation Engine

Supports: the Methodology section's seismic/flood damage modeling and SUMO traffic
simulation, and the Case Study Overview's "20 PGV realizations, N=130 MCR" description.

## Contents

- `Earthquake Damage Creation Considering Rehabilitation Policy.py` — generates per-policy
  Monte Carlo earthquake damage-state draws from PGV field realizations, using
  `num_realizations = 20`, `num_mc = 130`.
- `Earthquake Hazard Modeling Damaged Network with Rehabilitation Policy and Additional
  Punishment.py` — builds the damaged SUMO network graph and computes traffic-delay
  consequence (ADC) from the damage draws above.
- `Flood Damage Scenario Creation Considering Rehabilitation Policy.py` — generates
  per-policy Monte Carlo flood damage scenarios, using `n_runs_per_policy = 130`.
- `Flood Hazrad Modeling Damaged Network with Rehabilitation Policy and Additional
  Punishment.py` — flood-side analogue of the earthquake hazard-modeling script.
- `Edge_with_Avg_PGV.xlsx`, `Flood Depth in inch with traffic stop mark - Cleaned.xlsx` —
  small per-edge lookup inputs (PGV field / flood-depth-by-hour) — see "Required inputs" below
  for the full schema.

## Required inputs

Place a copy next to each script that references it (this folder's root, and every
subfolder listed below).

- **`Edge_with_Avg_PGV.xlsx`** — per-edge ground-motion intensity, one row per SUMO network
  edge (7,251 rows). Columns: `Edge ID`, `Start Node X/Y (DMS)`, `End Node X/Y (DMS)`,
  `Start Node X/Y (Decimal)`, `End Node X/Y (Decimal)`, `Edge Avg PGV`, and per-quartile PGV
  draws `PGV_0`, `PGV_25`, `PGV_50`, `PGV_75`, `PGV_100`. Example row: `Edge ID=-1001340249`,
  `Edge Avg PGV=22.3386`, `PGV_0..PGV_100` all `22.3386` (uniform across quartiles for that
  edge). Generated by the **OpenSHA ShakeMap Calculator** (Figure 3a).
- **`Flood Depth in inch with traffic stop mark - Cleaned.xlsx`** — per-edge, per-hour flood
  depth, same 7,251-row edge indexing. Columns: `Edge ID`, `Start/End Node Depth {0,1,2,3}
  Hour(s) (in)`, plus `Hour 0..Hour 3` (largely empty traffic-stop-mark columns in the sampled
  rows). Example row: `Edge ID=-1001340249`, `Start Node Depth 0 Hours (in)=0.011929`, `End
  Node Depth 0 Hours (in)=0.013268`, depths decreasing to 0 by hour 3. Generated by
  **ArcGIS Pro** flood inundation modeling (Figure 5).

## Requirements

- **`MapData/` (SUMO network files, `arden_arcade.net.xml` + `.rou.xml`)** — required by
  every script in this engine and every subfolder above. Place a `MapData/` subfolder next
  to each script that references it (see each script's path comments).

## External tools (not part of this Python codebase)

- **OpenSHA ShakeMap Calculator** — generates the PGV field realizations (Figure 3a) consumed
  as `Edge_with_Avg_PGV*.xlsx`.
- **ArcGIS Pro** — generates the flood inundation depths (Figure 5) consumed as the
  `Flood Depth in inch with traffic stop mark - Cleaned.xlsx` input.

Both are external GUI/commercial tools; their outputs are treated as inputs here.
